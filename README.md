# java-grundlagen-portfolio

Drei kleine Konsolenprojekte in Java, die meine Grundkenntnisse zeigen: von Variablen und Schleifen bis zu Methoden und Arrays. Bewusst ohne Frameworks und ohne Zusatzbibliotheken, nur mit der Java-Standardbibliothek.

Projekte:

Taschenrechner: Rechnet mit + - * / %, prüft Eingaben und fängt Division durch 0 ab.
Zahlenraten: Der Computer denkt sich eine Zahl aus, du rätst mit Hinweisen „zu klein“ / „zu groß“. Drei Schwierigkeitsstufen und Statistik über mehrere Runden.
Galgenraten: Ein zufälliges Wort wird Buchstabe für Buchstabe erraten, mit Galgen in ASCII-Grafik. Nach 6 Fehlern ist das Spiel verloren.

Was ich damit zeige:

- Variablen, Datentypen (int, double, char, boolean, String)
- Verzweigungen: if / else und switch
- Schleifen: while und for
- Eigene Methoden mit Parametern und Rückgabewerten
- Arrays eindimensional, auch zum Speichern von Zuständen (z. B. benutzte Buchstaben)
- Benutzereingaben mit Scanner und robuste Fehlerbehandlung bei falschen Eingaben
- Lesbarer Code mit sprechenden Namen und Kommentaren

Voraussetzung: ein installiertes JDK (Java 11 oder neuer).

(Erstellt im Rahmen meiner Fachoberschule, um den Praxispartnern meine Grundkenntnisse zu zeigen)
